# APP-Finance

Aplicação web simples para gestão financeira pessoal. Registre receitas e despesas, acompanhe o saldo e mantenha seu histórico salvo no navegador.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Preencha a descrição, categoria, tipo e valor.
3. Clique em **Adicionar** para registrar a movimentação.
4. Use o botão **Limpar tudo** para reiniciar o histórico.

Os dados ficam salvos no `localStorage` do navegador.
